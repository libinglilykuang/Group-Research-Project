# Test Cases

1. **Rendering**
- **TC1:** Load the graph without parameters and verify it displays correctly.
- **TC2:** Input a small dataset and confirm graph scaling.
- **TC3:** Load a dataset with multiple compression methods and ensure all data is
plotted.
2. **User Interaction**
- **TC4:** Change one parameter (e.g., accuracy) and check the graph updates.
- **TC5:** Select two compression methods for comparison and confirm visual accuracy.
- **TC6:** Input an invalid parameter and verify the error message.
3. **Data Integrity**
- **TC7:** Cross-check plotted data points with raw dataset values.
- **TC8:** Test extreme values for parameters and observe graph behavior.
4. **Responsive Design**
- **TC9:** Test the graph on different screen sizes and devices (desktop, tablet, mobile).
- **TC10:** Verify scaling and readability of the graph elements on smaller screens.
5. **Performance**
- **TC11:** Input a large dataset and measure graph rendering speed.
- **TC12:** Simulate real-time data updates and ensure no performance degradation.
6. **Export Functionality**
- **TC13:** Export the graph as an image and verify the resolution.
- **TC14:** Export the data and confirm it matches the visualized graph.
